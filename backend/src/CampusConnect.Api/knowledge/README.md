# Knowledge base for the CampusConnect assistant

These Markdown files are the ONLY facts the chatbot may answer from (plus the signed-in user's own complaints).
They describe how CampusConnect behaves today. To teach the assistant real university policies (fees, hours,
contacts, procedures), add or edit `.md` files here — one topic per `##` heading, short paragraphs — and redeploy.
Do not put personal data or secrets in these files.
